# 🎮 Steam Games Market Analysis Dashboard

An interactive **Streamlit dashboard** for analyzing the Steam Games dataset using **Python, Pandas, Plotly, and Streamlit**. This project provides insights into game popularity, pricing strategies, publishers, genres, player engagement, and market trends through interactive visualizations.

---

## 📌 Project Overview

The Steam Games Market Analysis Dashboard is a data visualization project developed to explore and analyze the Steam Games dataset. The dashboard enables users to filter games by genre, publisher, age rating, and price while providing meaningful insights through interactive charts and key performance indicators.

The application demonstrates how data visualization can transform raw gaming data into actionable insights for developers, publishers, and gaming enthusiasts.

- Game Name
- Genre
- Publisher
- Developer
- Price
- User Score
- Positive Reviews
- Negative Reviews
- Peak Concurrent Users
- Recommendations
- Release Date
- Achievements

Due to GitHub file size limitations, the dataset is loaded externally during application runtime.

## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/gireeshtripuraneni/Steam-Games-Market-Analysis.git
```

Navigate into the project directory

```bash
cd Steam-Games-Market-Analysis
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```

## 📌 Key Insights

- Steam hosts thousands of games across multiple genres.
- Action and Indie games dominate the platform.
- Positive reviews strongly correlate with recommendations.
- User engagement has a greater influence on popularity than price.
- High user scores generally correspond to increased recommendations and player activity.
